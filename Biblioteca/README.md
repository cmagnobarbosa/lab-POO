## Laboratorio de POO

Este repositorio reune projetos praticos para aprender Programacao Orientada a Objetos com Java.

O primeiro projeto e o sistema simples de biblioteca. Ele foi pensado para quem esta tendo o primeiro contato com Java e apresenta, passo a passo, conceitos como classe, objeto, atributos, metodos, construtor, encapsulamento, pacotes e listas.

Para comecar, leia o guia:

```text
GUIA_IMPLEMENTACAO.md
```

Depois execute o projeto:

```bash
javac Main.java biblioteca/Livro.java
java Main
```
